# 1V99 Ecossistema App

A Windows desktop application (WPF / C# XAML) that displays the **1V99 Ecossistema** landing page with a dark theme and gold accents.

## Screenshot Reference

The app replicates the design from the provided screenshot, including:

- **Header** – Crown logo, "ESCOLHA SEU CAMINHO" subtitle, and "NOSSO ECOSSISTEMA" title
- **Four ecosystem cards**:
  - 01 – FIVEM SERVER / FIVEM
  - 02 – MEDIA PORTAL / CREATORS
  - 03 – OFFICIAL MERCH / STORE (BREVE)
  - 04 – CONFIG PORTAL / CONFIGS
- **Footer** – "BE THE ONE." tagline, social media buttons, and © 2026 1V99

## Requirements

- Windows 10/11
- .NET 8.0 SDK or later

## How to Build & Run

```bash
cd EcossistemaApp
dotnet restore
dotnet run --project EcossistemaApp
```

Or open `EcossistemaApp/EcossistemaApp.sln` in Visual Studio 2022+ and press **F5**.
